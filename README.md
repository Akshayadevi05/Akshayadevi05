## 🚀 Featured Project

### 🏥 Smart Predictive Hospital Queue and Appointment Management System

A full-stack hospital management system with a **priority-based patient queue** that re-orders patients by urgency.

**Highlights**
- 4 modules: Patients, Doctors, Departments, Queue, with full CRUD through 15+ REST API endpoints
- 3 urgency levels (`NORMAL`, `PRIORITY`, `EMERGENCY`) with automatic queue re-sequencing
- Queue lifecycle: `WAITING → SERVING → COMPLETED / CANCELLED`
- Layered Spring Boot architecture (Controller, Service, Repository) with global exception handling and validation
- Responsive React.js dashboard connected to the backend APIs

**Tech:** Java · Spring Boot · Spring Data JPA · JPQL · MySQL · React.js · REST APIs · Postman
